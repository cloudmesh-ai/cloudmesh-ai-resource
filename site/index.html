    Cloudmesh AI Resource Extension

    cloudmesh-ai-resources is a powerful monitoring extension for the Cloudmesh AI CMC framework, specifically designed for High-Performance Computing (HPC) environments using the Slurm Workload Manager.

    It allows administrators and users to monitor the real-time health, resource utilization, and job status of remote compute nodes without requiring manual login to each node.

    🚀 Core Capabilities

    The extension bridges the gap between the CMC command-line interface and remote Slurm clusters:

    📊 Resource Monitoring

    • Real-time Metrics: Get immediate visibility into CPU, Memory, and GPU (specifically A100) utilization.
    • Node Health: Monitor node states (Allocated, Idle, Down, Drained) across the cluster.
    • GPU-Specific Insights: Detailed breakdown of GPU usage to optimize job scheduling.

    📋 Job Tracking

    • Active Job Summary: View who is running what, for how long, and what resources they are consuming.
    • Pending Queue Analysis: Identify why jobs are pending (e.g., Priority, Resources) to troubleshoot scheduling delays.
    • Deep-Dive Job Inspection: Fetch full scontrol details for any specific job ID.

    🌐 Remote Connectivity

    • SSH Integration: Securely connects to clusters using standard SSH configurations (~/.ssh/config).
    • Jump Host Support: Seamlessly route requests through gateway/jump hosts.
    • Persistent Connections: Optimized for speed and stability during "watch" mode.

    🛠️ Installation

    From PyPI

    pip install cloudmesh-ai-resource

    From Local Directory (Development)

    git clone https://github.com/cloudmesh-ai/cloudmesh-ai-resources.git
cd cloudmesh-ai-resources
pip install -e .

    Using pipx (Recommended for CLI)

    pipx install cloudmesh-ai-resource

    🏗️ Architecture

    The extension uses a Client-Server model via SSH: 1. Local CLI: Processes user input and manages SSH sessions. 2. Remote Cluster: Executes Slurm commands (sinfo, squeue, scontrol) and returns raw data. 3. Parser: Converts raw Slurm output into structured Python dataclasses for reporting or JSON export.
